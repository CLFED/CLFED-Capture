# CLFED Capture

A Windows game recorder by Talal (CLFED), with Instant Replay, separate Discord, app, and microphone volume, clip trimming, custom keybinds, and Arabic and English.

Download the installer from the [latest release](https://github.com/CLFED/CLFED-Capture/releases/latest). Installed copies offer new versions automatically.

## Build

Needs Node.js, Python with `ziglang`, and the NSIS files that electron-builder downloads. Run `npm run release` to build and publish.
